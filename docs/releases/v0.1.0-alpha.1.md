# Runnel v0.1.0-alpha.1

**Release type:** prerelease — first exact target-model optimization.

## What is released

- a usable streaming CLI for Ornith/Qwen3.5 local checkpoints;
- packed routed gate/up execution, replacing two top-8 expert gathers per layer with one;
- checkpoint/environment/runtime fingerprints;
- fixed-token benchmark and component-profiling tools;
- raw M1 Max results and negative experiments.

## Correctness

The optimization is called **exact only relative to the pinned project reference**:

- `mlx-lm` commit `15bcf8b929e5da67aa7f8fe6feda7fb9eda00050`;
- MLX 0.32.2;
- checkpoint revision `02440c39bdf7365c494a7f55f2a8b104ba87562f` for 8-bit and `19504d912fa8fc7622bf6b1de3db5d5d890b1f02` for official 4-bit;
- greedy sampling, batch 1, 64 output tokens, one warmup, three measured trials.

All kept-optimization trials in the release matched the corresponding reference greedy token-ID stream. oMLX is retained as a separate numerical/performance baseline because its greedy output differs.

## Hardware

- Apple M1 Max, 32 GPU cores;
- 64 GB unified memory;
- macOS 27.2 build `26B5086k`;
- Xcode 26.6, Metal compiler 32023.883;
- AC power; exact memory/power snapshots are in the linked raw environments.

## Protocol and results

Raw records: `bench/results/m0/`.

| Checkpoint/context | Reference decode | Runnel decode | Median gain |
|---|---:|---:|---:|
| 8-bit / 1K | 52.61 tok/s | 56.53 tok/s | +7.44% |
| 8-bit / 8K | 50.09 tok/s | 52.51 tok/s | +4.84% |
| official 4-bit / 1K | 68.45 tok/s | 73.15 tok/s | +6.86% |
| official 4-bit / 8K | 61.94 tok/s | 65.40 tok/s | +5.58% |

Each JSON record retains every trial, prompt digest, checkpoint manifest, runtime identity, environment capture digest, cache state, timing distribution, peak MLX memory, and correctness status.

## Known limitations

- This is an alpha research runtime, not a stable server distribution.
- The gain is meaningful but well below the 2× target.
- oMLX 0.7.0.dev4 is faster in the official 4-bit lane (75.18 tok/s observed at 1K), though not greedy-identical to the project reference.
- Only 1K and 8K fixed-prompt sweeps are included.
- No native Metal kernel, MTP drafter, exact GDN rollback, or OpenAI API is included.
- Full Transformers/PyTorch independent parity remains pending.

## Upgrade warning

Do not use this alpha for unattended production serving. Use the model/runtime's established server while the long-context, state-restore, and independent correctness work continues.
