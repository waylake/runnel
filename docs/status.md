- `Qwen3_5MoeForConditionalGeneration` / `qwen3_5_moe`;
- 40 decoder layers: 30 linear-attention + 10 full-attention layers;
- hidden size 2048; 16 full-attention query heads; 2 KV heads; head dimension 256;
- 256 routed experts, top-8, one shared expert, MoE intermediate size 512;
- 8-bit affine quantized MLX checkpoint; 34,660,608,768 logical parameters; 36,827,986,176 stored bytes;
- Qwen2 tokenizer, vocab 248,320, native maximum position 262,144;
- config declares one MTP hidden layer, but the current weight map contains **no tensor name containing `mtp`**; MTP is therefore not available in this exact checkpoint unless a runtime treats another module as a drafter.

Small-file SHA-256 values and full shard manifest are generated by `runnel-fingerprint` and must be attached to benchmark trials.

## Current hypothesis

The fastest credible frontier is likely a specialized MLX/Metal hybrid rather than a generic Transformer server, but the first bottleneck is not yet established. The 8-bit checkpoint makes weight traffic important, while the 30 Gated DeltaNet layers, 256-way expert dispatch, quantized grouped GEMMs, and ~508M-parameter LM head may create larger execution-specific overheads.
